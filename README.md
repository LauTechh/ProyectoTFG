# Libros y Patatas 🥔

## Descripción del proyecto
**Libros y Patatas** es una red social orientada a lectores desarrollada como Trabajo de Fin de Grado. 
La aplicación permite a los usuarios gestionar su estantería de libros de forma personalizada, realizar un seguimiento de sus lecturas, 
interactuar con otros usuarios.

## Objetivos
* Desarrollar una plataforma que facilite la gestión de bibliotecas personales y estados de lectura.
* Implementar una estructura de red social para fomentar la interacción entre usuarios con intereses literarios comunes.
* Aplicar tecnologías modernas (Laravel, MySQL, Docker) para construir una aplicación escalable y eficiente.
* Garantizar la correcta configuración, despliegue y puesta en marcha del proyecto en un entorno de desarrollo.

## Tecnologías utilizadas
* **Backend:** PHP, Laravel Framework.
* **Base de datos:** MySQL.
* **Entorno:** Docker y Docker Compose.
* **Frontend:** Blade Templates, CSS3, JavaScript.
* **Control de versiones:** Git y GitHub.

## Instrucciones básicas para utilizar el proyecto
Para visualizar el proyecto en local, sigue estos pasos:

1. **Clonar el repositorio:**
   `git clone https://github.com/LauTechh/ProyectoTFG.git`
2. **Levantar los contenedores:**
   `docker-compose up -d`
3. **Instalar dependencias y migraciones:**
   `composer install`
   `php artisan migrate`
4. **Acceder:**
   Abre tu navegador y entra en `http://localhost`.
